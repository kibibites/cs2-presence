# cs2 presence

discord rich presence for counter strike 2.

## usage

1. download the [config file](https://raw.githubusercontent.com/kibibites/cs2-presence/refs/heads/mistress/gamestate_integration_cs2presence.cfg)

2. move the config file here:
  - windows: `C:\Program Files (x86)\Steam\steamapps\common\Counter-Strike Global Offensive\game\csgo\cfg`
  - linux: idk you should probably know this though

3. download either the [windows](https://github.com/kibibites/cs2-presence/releases/download/1.0.0/cs2-presence.exe.xz) or [linux](https://github.com/kibibites/cs2-presence/releases/download/1.0.0/cs2-presence.xz) executable.

4. extract and run the executable, and start your game

5. profit
